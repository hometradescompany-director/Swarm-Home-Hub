# Start a Paid Pilot

Swarm Home Hub is a public proof surface for a bounded agent residence and readiness architecture. A paid engagement is deliberately narrower than a platform rewrite.

## The smallest useful pilot

Bring four things:

1. one agent or automation that currently creates operational uncertainty;
2. one authoritative identity or permission source;
3. one state transition you need to explain after the fact;
4. one failure that must never silently pass.

That is enough to decide whether a bounded pilot is worth doing.

## What the pilot produces

A pilot is scoped around one real workflow and can produce:

- an authority-boundary map;
- an explicit event and state-transition model;
- a bounded integration or proof implementation;
- an inspectable event and evidence path;
- fail-closed tests for missing or denied authority;
- a technical handoff describing what should stay local and what must remain owned by existing systems.

The goal is observable evidence, not a presentation layer.

## Commercial boundary

Custom implementation is paid work.

Before bespoke engineering begins, scope, deliverables, commercial terms, and the handoff boundary are agreed in writing. A pilot does not transfer Atlas ownership, customer source-of-truth ownership, or unrestricted authority to Swarm Home Hub.

The public repository is inspectable proof. Public visibility does not grant an open-source license or rights beyond the terms in [LEGAL.md](../LEGAL.md).
