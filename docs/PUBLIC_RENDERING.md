# Public residence rendering

The visual surface in `site/` is a projection over the real Swarm Home residence
model. It imports `projectResidence()` from the repository and constructs the
display from append-only demo event histories.

It does not create a second residence state machine.

## Rendered concepts

- requested -> admitted -> resting -> ready -> departed;
- current residence snapshots and versions;
- append-only event counts;
- habitat as local context;
- No King and presence-is-not-authority posture;
- the single bounded "door" idea across transport/provider adapters.

The seeded identities are fictional opaque references. The page does not claim
that a displayed resident is a live agent, current provider session, Atlas
identity, or externally authorised principal.
