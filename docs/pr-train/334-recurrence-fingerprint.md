# PR Train Slot 334: Recurrence fingerprint contract

Status: **planned contract slice, not runtime implementation**
Phase: **333-344 · Facehugger Observatory contracts**

## Intent
Represent repeat appearances of a candidate capability across contexts without collapsing distinct events.

## Boundary
A fingerprint groups comparable observations; it is not proof of common cause or identity.

## Gate
Require explicit feature basis, comparison method, source receipts, and contradiction links.

## Falsification
Reject if similarity becomes identity, recurrence is inferred from naming alone, or contradictory observations are discarded.
