# MCP 2026-07-28 profile

Swarm Home exposes its existing transport-neutral tool router through a bounded,
stateless Model Context Protocol adapter.

## Architecture

\`\`\`text
MCP client
   |
   v
SwarmHomeMcpWebTransport
   |
   v
SwarmHomeMcpAdapter
   |
   v
SwarmHomeToolRouter
   |
   v
SwarmHomeDoor
   |
existing residence services / event journal / Atlas contracts
\`\`\`

The MCP layer owns **protocol framing only**.

It does not own:
- residence state;
- Atlas identity or authority;
- agent memory;
- task state;
- a second event store;
- MCP sessions.

## Supported profile

Protocol version: \`2026-07-28\`

Supported methods:
- \`server/discover\`
- \`tools/list\`
- \`tools/call\`

The adapter intentionally does not implement prompts, resources, subscriptions,
tasks or legacy session/initialize semantics until Swarm Home has a real local
responsibility requiring them.

## Exposure

Read-only tools are exposed by default.

State-mutating tools require two explicit decisions:
1. the MCP adapter is constructed with \`exposure: "all"\`;
2. the HTTP host supplies an admission guard for the mutating call.

Transport connectivity is not authority.
