# Identity Lineage

Status: current public naming projection as of 2026-09-23.

## Current stack

# Swarm Topology

### Swarm Home Base

**Originating lineage: Swarm Home Hub**

Swarm Topology is the current public system identity for this repository as the work extends beyond the original residence/readiness surface into bounded relationships between homes, agents, capabilities, evidence, providers, workloads, handoffs, placement and execution surfaces.

Swarm Home Base is the bounded residence/readiness kernel inside that wider topology.

Swarm Home Hub remains the historical originating name. It is not erased, rewritten, or treated as a mistake.

## Relationship

The naming transition is a successor relationship, not a replacement of history:

```text
Swarm Home Hub
      |
      v
Swarm Home Base  -- bounded residence/readiness kernel
      |
      v
Swarm Topology   -- current public system identity
```

The older identity remains valid when describing historical commits, pull requests, documents, package names, routes, schemas, events, contracts, screenshots, correspondence, and other source-near evidence created under that name.

## Compatibility rule

This naming change does **not** authorize a destructive global rename.

Existing technical identifiers such as `SwarmHome...`, `swarm.residence.*`, `SwarmAtlasFederation/v1`, package names, repository URLs and other versioned interfaces remain unchanged unless a separate compatibility-reviewed migration justifies changing them.

A new public name does not silently change protocol identity.

## Boundary

The rename changes no authority boundary.

- Swarm Home Base still owns only its bounded residence/readiness truth.
- Atlas remains the external identity, authority and orchestration boundary where existing contracts say it does.
- Evidence does not become authority.
- Connectivity does not become authority.
- A topology relationship does not itself grant authority.
- No new truth store or parallel state machine is introduced by this naming layer.

## Provenance rule

Future documentation should prefer the current public stack:

**Swarm Topology · Swarm Home Base**

When historical precision matters, preserve **Swarm Home Hub** exactly where it occurred rather than retrospectively rewriting the record.
